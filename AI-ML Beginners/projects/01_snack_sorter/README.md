# The Snack Sorter

**Category:** No-Code Intuition Builders (code version)  
**Algorithm:** K-Nearest Neighbors  
**Style:** Low-code Python (the original no-code tool is Google Teachable Machine)

## The concept

You show a computer tiny photos of three snacks and teach it to tell them apart. The AI turns each photo into five simple numbers—average colour, colour coverage, and shape—then compares a new photo with the examples it has already seen. It is like recognising a friend's face after seeing it many times.

## What you will build

Train a KNN classifier on 90 generated snack photos, test it on 23 photos it has never seen, and save a prediction grid, a confusion matrix, and a metrics report.

## Run it

```bash
cd projects/01_snack_sorter
python main.py
```

If you are using Google Colab, upload the whole project folder and run the same command in a code cell with `!python main.py`.

## Files

- `main.py` — the complete, runnable project
- `data/` — the small dataset used by the project
- `outputs/` — charts, predictions, and summaries created when you run the script

## What you will see

The script saves: `sample_snacks.png`, `predictions.png`, `confusion_matrix.png`, `metrics.txt`

## What you will learn

Image classification and how the examples you provide shape what the model can recognise.

## Try this

Add a fourth snack class (for example, a biscuit), regenerate the dataset, and retrain.

## A note

The photos are generated by `build_data.py`, so this runs offline. For the full no-code experience, use Google Teachable Machine with your webcam.
