# Setup Guide - MIT App Inventor

## Getting Started with MIT App Inventor (No Installation Required!)

### What is MIT App Inventor?
MIT App Inventor is a free, browser-based platform that lets you create Android apps using a visual, drag-and-drop interface. Instead of writing code, you snap together colorful "blocks" that represent programming concepts — like puzzle pieces that only fit together in logical ways.

### Prerequisites
- A Google account (Gmail)
- An Android phone (for testing with the AI2 Companion app)
- OR a computer that can run an Android emulator

### Step 1: Access App Inventor
1. Go to [https://ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu)
2. Sign in with your Google account
3. You'll be taken to the "Projects" dashboard

### Step 2: Install the AI2 Companion App (for live testing)
1. On your Android phone, open the Google Play Store
2. Search for "MIT AI2 Companion"
3. Install the app

### Step 3: Create Your First Project
1. Click "Create Apps" → "Start New Project"
2. Name your project (e.g., "HelloWorld")
3. Click "Create"

### Step 4: Test on Your Phone
1. On the App Inventor website, click "Connect" → "AI2 Companion"
2. A QR code will appear
3. On your phone, open the AI2 Companion app
4. Tap "Scan QR Code" and scan the code
5. Your app will instantly appear on your phone!

### Step 5: Explore the Interface
- **Designer Tab**: Drag and drop UI components (buttons, text, images) onto your screen
- **Blocks Tab**: Snap together blocks to create your app's logic (event handling, calculations, etc.)

### Common Components You'll Use
| Category | Components |
|----------|-----------|
| **User Interface** | Button, Label, TextBox, ListPicker, Image, Canvas |
| **Sensors** | Accelerometer, Clock, LocationSensor |
| **Storage** | TinyDB, TinyWebDB, Storage File |
| **Connectivity** | WebViewer, ActivityStarter, Bluetooth |
| **Media** | Player, Sound, Camera, VideoPlayer |

### Tips for Success
- Start simple: Build a "Hello World" app first
- Test often: Use the AI2 Companion to see changes instantly
- Save your work: App Inventor auto-saves, but it's good practice
- Use the "Help" menu for built-in tutorials
- Check the "Projects" page to access your saved projects anytime
