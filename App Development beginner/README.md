## Getting Started Guide

### Option 1: Block-Based Projects (Categories 1)
- Uses **MIT App Inventor** (browser-based, no installation needed)
- Create a free account at [ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu)
- Install the **MIT AI2 Companion** app on your Android phone
- Scan QR codes to test your apps instantly on your phone

### Option 2: Flutter Projects (Categories 2-4)
1. **Install Flutter**: Download from [flutter.dev](https://flutter.dev), extract, and add to PATH
2. **Install VS Code**: Download from [code.visualstudio.com](https://code.visualstudio.com)
3. **Install Extensions**: Flutter and Dart extensions in VS Code
4. **Set up Android Emulator**: Install Android Studio, create a virtual device, or use a real phone with USB debugging

### Quick Start Commands
```bash
# Create a new Flutter project
flutter create project_name
cd project_name

# Install dependencies
flutter pub get

# Run on connected device or emulator
flutter run
```

## Learning Path Recommendation

**Week 1-2**: Start with Category 1 (MIT App Inventor) to get comfortable with app concepts
**Week 3-4**: Move to Category 2 (Flutter utilities) to learn real coding
**Week 5-6**: Build Category 3 (Games) for engaging challenge projects
**Week 7-8**: Complete Category 4 (API integration) for advanced web connectivity
