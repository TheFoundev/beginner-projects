About This Project

This website is a static site deployed on Vercel — a platform built for frontend developers. It features:

  • ✅ Global Content Delivery Network (CDN) — loads instantly worldwide
  • ✅ Automatic SSL certificates — secure by default
  • ✅ Instant cache invalidation — updates appear in seconds
  • ✅ Preview deployments — every branch gets its own URL
  • ✅ Serverless functions — add backend logic without a server

This project demonstrates how to build and deploy a static site with interactive features using only HTML, CSS, and vanilla JavaScript.
