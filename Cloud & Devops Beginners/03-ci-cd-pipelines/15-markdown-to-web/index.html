A blog about learning Cloud Computing and DevOps from scratch.

Week 1: Introduction to the Cloud

Today I learned what cloud computing is! Instead of owning physical computers, we rent computing power on-demand. The three main types are:

  • IaaS — Infrastructure as a Service (e.g., AWS EC2)
  • PaaS — Platform as a Service (e.g., Google App Engine)
  • SaaS — Software as a Service (e.g., Gmail)
Pro tip: Start with free tiers to experiment without spending money!

Week 2: Version Control with Git

I'm learning to use git for tracking changes to my code. Key commands:

git add .
git commit -m "My changes"
git push origin main
