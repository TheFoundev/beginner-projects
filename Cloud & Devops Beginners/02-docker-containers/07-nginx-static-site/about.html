About This Project

This multi-page website is containerized with Docker and served by Nginx. It demonstrates how to:

  • Serve multiple static HTML pages from a single container
  • Use a real web server (Nginx) instead of Python's built-in server
  • Implement a responsive navigation bar with a mobile hamburger menu
  • Maintain consistent styling across multiple pages
  • Track visitors using JavaScript and localStorage

Tech Stack

HTML5 CSS3 / Flexbox Grids Vanilla JavaScript Docker Nginx
